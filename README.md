# Euphony

Private build of a YouTube Music client for Android — for personal use only.
Not affiliated with, endorsed by, or an official release of ArchiveTune.

## Origin

Euphony is a modified fork of ArchiveTune (GPL-3.0), itself descended from
Metrolist / InnerTune. See [NOTICE.md](NOTICE.md) for full credit and the
license terms. The original project lives at
https://github.com/rukamori/ArchiveTune — this build is not that project.

## Identity

- App name: Euphony
- Application ID: `id.euphony.app`
- Version: 1.0.0 (version code 1)
- Updater, upstream data server, and Discord integration are disabled:
  this build contacts no upstream server.

## Build

Standard Android build (AGP 9.4.1, compileSdk 37, JVM 21). A release
keystore is required; none is bundled with this tree.
